Проект содержит UI-автотесты для учебного сервиса "Яндекс.Самокат"

Особенности реализации
1. Page Object Model - строгое разделение логики тестов и работы с элементами
2. Параметризация - для тестирования разных сценариев с общим кодом
3. Allure-отчеты - детальная информация о выполнении тестов
4. Явные ожидания - стабильность тестов при загрузке элементов

Нужно проверить:
1. Вопросы о важном
- Параметризованный тест для 8 вопросов, который отображает правильные ответы на каждый из них
2. Заказ самоката
- Позитивный сценарий с двумя наборами данных
- Проверка верхней и нижней кнопок "Заказать"
- Полный флоу заказа:
+ Заполнение персональных данных
+ Указание параметров аренды
+ Подтверждение заказа
3. Проверка редиректов:
- Логотип Самоката - Главная страница
- Логотип Яндекса - Дзен (в новой вкладке)
